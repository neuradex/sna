HTTP API は表面別にまとまっています。以下の各パスはエンドポイント別の詳細仕様ページへリンクします。

## システム

| メソッド | パス | 用途 |
|--------|------|---------|
| `GET` | [`/health`](/ja/docs/api/endpoints/health/get) | Health check |
| `GET` | [`/api/sna-port`](/ja/docs/api/endpoints/api/sna-port/get) | 現在の SNA API ポート取得 |

## セッション

| メソッド | パス | 用途 |
|--------|------|---------|
| `POST` | [`/agent/sessions`](/ja/docs/api/endpoints/agent/sessions/post) | セッションレコード作成 |
| `GET` | [`/agent/sessions`](/ja/docs/api/endpoints/agent/sessions/get) | セッション一覧取得 |
| `PATCH` | [`/agent/sessions/{id}`](/ja/docs/api/endpoints/agent/sessions/id/patch) | label、meta、cwd を更新 |
| `DELETE` | [`/agent/sessions/{id}`](/ja/docs/api/endpoints/agent/sessions/id/delete) | セッションと履歴を削除 |

## レスポンス形

ほとんどの SDK-facing レスポンスは `server/api-types.ts` の envelope に従います。streaming と binary エンドポイントは wire-native なレスポンス本文を使います。正確な schema はライブ OpenAPI ドキュメントで確認してください。

```ts
type ApiResponse<T> =
  | { status: "ok"; data: T }
  | { status: "error"; message: string; code?: string };
```

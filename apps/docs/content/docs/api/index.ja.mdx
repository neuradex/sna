## 真実の源

サーバの Hono アプリは `@hono/zod-openapi` ルート定義からビルドされ
る。稼働中サーバは同じ Zod スキーマから生成された OpenAPI 3.1 仕様を
自身が提供する。よってここで見るワイヤ形、SDK 型、ライブ仕様が
ドリフトすることはない。

| URL | 用途 |
|-----|------|
| `GET /openapi.json` | 生の仕様 JSON |
| `GET /docs` | Swagger UI |
| `GET /spec` | プレーンテキスト仕様 |

迷ったらライブサーバを叩け。常にこのページより権威がある。

## 真実の源

サーバの Hono アプリは `@hono/zod-openapi` ルート定義からビルドされます。
稼働中サーバは、同じ Zod スキーマから生成された OpenAPI 3.1 仕様を
自身で提供します。そのため、ここで見るワイヤ形、SDK 型、ライブ仕様が
ドリフトすることはありません。

| URL | 用途 |
|-----|------|
| `GET /openapi.json` | 生の仕様 JSON |
| `GET /docs` | Swagger UI |
| `GET /spec` | プレーンテキスト仕様 |

確認が必要な場合は、ライブサーバのスペックを直接参照してください。
ライブスペックが常にこのページより権威のある基準です。

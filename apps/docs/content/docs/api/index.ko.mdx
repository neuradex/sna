## 진실의 원천

서버의 Hono 앱은 `@hono/zod-openapi` 라우트 정의로 빌드된다. 구동 중인
서버는 같은 Zod 스키마에서 생성한 OpenAPI 3.1 스펙을 자체적으로
제공한다. 따라서 여기 보이는 와이어 모양, SDK 타입, 라이브 스펙은
서로 드리프트할 수 없다.

| URL | 용도 |
|-----|------|
| `GET /openapi.json` | 원시 스펙 JSON |
| `GET /docs` | Swagger UI |
| `GET /spec` | 평문 스펙 |

의심스러우면 라이브 서버를 두드려 봐라. 항상 이 페이지보다 더 권위
있다.

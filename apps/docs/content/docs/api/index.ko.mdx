## 계약의 기준

서버의 Hono 앱은 `@hono/zod-openapi` 라우트 정의로 빌드됩니다. 실행 중인
서버는 같은 Zod 스키마에서 생성한 OpenAPI 3.1 스펙을 직접 제공합니다.
따라서 이 문서의 와이어 형태, SDK 타입, 라이브 스펙은 같은 소스에서
파생됩니다.

| URL | 용도 |
|-----|------|
| `GET /openapi.json` | 원시 스펙 JSON |
| `GET /docs` | Swagger UI |
| `GET /spec` | 평문 스펙 |

정확한 계약을 확인해야 할 때는 라이브 서버의 스펙을 직접 조회하세요.
라이브 스펙이 항상 최종 기준입니다.

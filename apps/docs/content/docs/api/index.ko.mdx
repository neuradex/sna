## 진실의 원천

서버의 Hono 앱은 `@hono/zod-openapi` 라우트 정의로 빌드됩니다. 구동 중인
서버는 같은 Zod 스키마에서 생성한 OpenAPI 3.1 스펙을 자체적으로
제공합니다. 따라서 여기 보이는 와이어 모양, SDK 타입, 라이브 스펙은
서로 드리프트할 수 없습니다.

| URL | 용도 |
|-----|------|
| `GET /openapi.json` | 원시 스펙 JSON |
| `GET /docs` | Swagger UI |
| `GET /spec` | 평문 스펙 |

확인이 필요할 때는 라이브 서버의 스펙을 직접 조회하세요. 라이브 스펙이
항상 이 문서보다 더 권위 있는 기준입니다.

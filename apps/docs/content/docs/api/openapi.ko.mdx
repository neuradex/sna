Hono 서버는 라우트가 쓰는 같은 Zod 스키마에서 생성한 OpenAPI 3.1
스펙을 자체적으로 제공한다. 동기화해야 할 별도의 스펙 파일은 없다.
스펙, SDK 타입, 라우트 핸들러가 모두 같은 한 소스에서 파생된다.

## 어디서 찾는지

서버가 구동 중일 때:

| URL | 포맷 |
|-----|------|
| `http://localhost:3099/openapi.json` | 원시 JSON (기계 판독 가능) |
| `http://localhost:3099/docs` | Swagger UI (인터랙티브) |
| `http://localhost:3099/spec` | 평문 덤프 |

`3099`는 `startSnaServer({ port })` 가 반환한 포트로 바꾸기.

## 유스케이스

- **다른 언어 클라이언트 생성.** `/openapi.json`에 아무 OpenAPI
  코드젠을 붙이기. 스키마가 strict (Zod 파생)이라 출력은 타입 안전.
- **인터랙티브 탐색.** Swagger UI에서 인증과 body 편집기를 갖고
  브라우저로 모든 라우트를 발사할 수 있다.
- **CI에서 계약 고정.** 스펙을 디스크로 스냅샷, 빌드마다 diff.
  의도치 않은 공개 표면 변경이 diff로 드러난다.

## 안정성

라우트는 SNA 워크스페이스 전반에서 semver를 따른다. 하위 호환 안 되는
라우트 변경은 메이저 버전으로 출시된다. OpenAPI 태그는 라우트를
표면별(Sessions, Agent, Permissions, Chat)로 묶어서 생성 클라이언트가
합리적인 그룹핑을 갖는다.

라우트와 한 줄 설명 전체 목록은 [HTTP 라우트](/docs/api/http) 참고.
각 라우트가 emit할 수 있는 이벤트 타입은 [이벤트](/docs/api/events)
참고.

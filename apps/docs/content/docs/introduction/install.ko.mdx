SNA는 세 개의 공개 패키지와 하나의 테스트 헬퍼 패키지로 배포됩니다.

| 패키지 | 역할 |
|--------|------|
| `@sna-sdk/core` | HTTP/WS 서버, session manager, providers, 정규화 히스토리 |
| `@sna-sdk/client` | 프레임워크 비종속 TypeScript 클라이언트 (HTTP + WS) |
| `@sna-sdk/react` | React 바인딩 (훅, 드롭인 채팅 UI) |
| `@sna-sdk/testing` | Mock Anthropic API + 격리된 Claude Code 테스트 환경 |

전체 패키지 표면은 [SDK 레퍼런스](/ko/docs/sdks)에서 확인할 수 있습니다.

## 컨슈머 앱에 추가하기

```bash
pnpm add @sna-sdk/core @sna-sdk/client
# React 앱이라면
pnpm add @sna-sdk/react
```

## 모노레포에서 작업하기

이 저장소는 pnpm 워크스페이스를 사용합니다. 저장소를 clone한 뒤
의존성을 설치하고 빌드합니다.

```bash
git clone https://github.com/neuradex/sna.git
cd sna
pnpm install
pnpm -r build
```

`pnpm -r build`는 모든 패키지를 토폴로지 순서대로 컴파일합니다. 빌드가
끝나면 `pnpm --filter @sna-sdk/core test`를 실행하거나 standalone 서버를
실행할 준비가 됩니다.

## 런타임 CLI 확인

SNA는 에이전트 바이너리가 `PATH`에 있다고 가정합니다. 다음 명령으로
빠르게 확인할 수 있습니다.

```bash
claude --version
codex --version
opencode --version
```

비표준 위치에 있다면 호출 시점에 `providerOptions.cliPath`로
오버라이드하거나, 환경 변수 `SNA_CLAUDE_PATH` / `SNA_CODEX_COMMAND`를
설정합니다.

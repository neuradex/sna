SNA はプロバイダ中立のランタイム統合を中心に設計されています。目的は、
各ネイティブエージェントを最小公分母の背後に隠すことではありません。
各ランタイムが提供する有用な意味を保ち、コンシューマアプリが依存すべき
部分だけを正規化することです。

このセクションでは、特定の API ルートや SDK パッケージを超える設計原則を
整理します。

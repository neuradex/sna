SNA はランタイム中立の統合を中心に設計されています。目的は、
各ネイティブエージェントを最小公分母の背後に隠すことではありません。
各ランタイムが持つ意味は保ち、アプリが依存すべき境界だけを正規化します。

このセクションでは、特定の API ルートや SDK パッケージを越える設計判断を
整理します。

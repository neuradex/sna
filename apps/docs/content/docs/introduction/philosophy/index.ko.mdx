SNA는 프로바이더 중립적인 런타임 통합을 중심으로 설계됩니다. 목표는 각
네이티브 에이전트를 최소 공통분모 뒤에 숨기는 것이 아니라, 각 런타임이
제공하는 유용한 의미를 보존하고 소비자 앱이 의존해야 하는 부분만
정규화하는 것입니다.

이 섹션에는 특정 API 라우트나 SDK 패키지를 넘어서는 설계 원칙을 정리합니다.

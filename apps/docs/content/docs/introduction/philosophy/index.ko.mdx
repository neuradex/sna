SNA는 런타임 중립적인 통합을 중심으로 설계됩니다. 목표는 각
네이티브 에이전트를 최소 공통분모 뒤에 숨기는 것이 아닙니다. 각 런타임이
가진 의미는 보존하고, 앱이 의존해야 하는 경계만 정규화합니다.

이 섹션은 특정 API 라우트나 SDK 패키지를 넘어서는 설계 판단을 정리합니다.

영(0)에서 라이브 이벤트까지 가는 가장 짧은 경로. 이 페이지를 다 읽고
나면 앱 안에서 SNA 서버가 돌고 있고, Claude Code(또는 Codex / OpenCode)에
붙은 세션이 열려 있고, 토큰이 WebSocket으로 흘러나오고 있을 거임.

## 무엇을 만드는지

SNA는 앱에 임베드하는 작은 서버다. **세션을 시작**하라고 요청하면
서버가 에이전트 CLI를 자식 프로세스로 띄우고 하나의 HTTP + WebSocket
API로 노출함. 소비자 입장에서는 백엔드에 말 거는 것처럼 보이지만
실제로는 진짜 Claude Code / Codex / OpenCode 프로세스가 일을 한다.

```
your app
   │
   │  HTTP for control (send, interrupt, kill, …)
   │  WS   for events (assistant_delta, tool_use, complete, …)
   ▼
SNA server  ──spawn──►  claude | codex | opencode
```

아래 5단계. 설계 선택의 *왜* (정규화된 히스토리, 런타임 교체, 어트리뷰션)에
대해서는 **[What is SNA?](/docs/quickstart/what-is-sna)** 를 참고.

## 사전 준비

- **Node.js 20+**.
- **`PATH`에 런타임 CLI 하나 이상**: `claude`, `codex`, `opencode` 중.
- 패키지 매니저. 예시는 `pnpm`을 쓰지만 npm / yarn / bun 모두 가능.

## 1. 설치

```bash
pnpm add @sna-sdk/core @sna-sdk/client
```

전체 사전 조건 + CLI 경로 오버라이드는 **[Install](/docs/quickstart/install)** 참고.

## 2. 서버 부팅

앱 안에서:

```ts
import { startSnaServer } from "@sna-sdk/core/node";

const sna = await startSnaServer({
  port: 3099,
  dbPath: "./data/sna.db",
});
```

SNA 서버가 관리되는 자식 프로세스로 fork됨. `sna.port`에 바인딩된
포트(0이면 자동 할당), `sna.stop()`이 SIGTERM 보냄.

## 3. 클라이언트 연결

```ts
import { SnaClient } from "@sna-sdk/client";

const client = new SnaClient({
  baseUrl: `localhost:${sna.port}`,
  http: true,   // POST /agent/* 등
  ws: true,     // 라이브 이벤트 스트림
});
client.connect();
```

## 4. 세션 열고 에이전트 시작

```ts
const { sessionId } = await client.sessions.create({ label: "scratch" });

await client.agent.start(sessionId, {
  provider: "claude-code",
  model: "claude-sonnet-4-6",
});
```

## 5. 이벤트 구독 → 메시지 전송

```ts
client.agent.onEvent(({ event }) => {
  if (event.type === "assistant_delta") process.stdout.write(event.delta as string);
  if (event.type === "tool_use") console.log("\n[tool]", event.message);
  if (event.type === "complete") console.log("\n[done]", event.data);
});
await client.agent.subscribe(sessionId);

await client.agent.send(sessionId, "List the files in this directory.");
```

이게 루프 전체. 토큰은 `assistant_delta`로 흘러오고, 툴 호출은
`tool_use`로 발화되고, 턴은 `complete` 이벤트로 끝나면서 사용량/비용을
같이 받음.

## 단발 호출만 필요하면?

세션도 이벤트도 필요 없고 답 하나만 받으면 되는 경우엔 `completion()`:

```ts
import { completion } from "@sna-sdk/core";

const result = await completion({
  prompt: "Summarize: ...",
  provider: "claude-code",
  model: "claude-haiku-4-5",
  onDelta: (chunk) => process.stdout.write(chunk),
});
// result.text, result.usage, result.costUsd, result.durationMs
```

3가지 스트리밍 변형(인프로세스 콜백, SSE, 전체 이벤트 스트림)에 대해선
**[Cookbook → Streaming](/docs/cookbook/streaming)** 참고.

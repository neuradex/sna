## Prerequisites

- **Node.js 20+** (the server uses the built-in test runner shape and modern ESM).
- **At least one runtime CLI on `PATH`.** SNA does not bundle the
  underlying agents — install whichever you plan to use:
  - `claude` (Claude Code) — `npm install -g @anthropic-ai/claude-code`
  - `codex` (Codex CLI) — see [openai/codex](https://github.com/openai/codex)
  - `opencode` — see [opencode/opencode](https://github.com/opencode-ai/opencode)
- **pnpm** is recommended for the workspace, but the published packages
  install fine with npm/yarn/bun in consumer apps.

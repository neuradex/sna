SNA は published パッケージ 3 つ + テスティングヘルパー 1 つを出荷
する。

| パッケージ | 役割 |
|------------|------|
| `@sna-sdk/core` | HTTP/WS サーバ、session manager、providers、正規化履歴 |
| `@sna-sdk/client` | フレームワーク非依存の TypeScript クライアント (HTTP + WS) |
| `@sna-sdk/react` | React バインディング (フック、ドロップイン chat UI) |
| `@sna-sdk/testing` | Mock Anthropic API + 隔離された Claude Code テスト環境 |

## コンシューマアプリへ追加

```bash
pnpm add @sna-sdk/core @sna-sdk/client
# React アプリならば
pnpm add @sna-sdk/react
```

## モノレポで作業する

レポは pnpm workspaces を使う。clone → install → build:

```bash
git clone https://github.com/neuradex/sna.git
cd sna
pnpm install
pnpm -r build
```

`pnpm -r build` がすべてのパッケージをトポロジ順にコンパイルする。
これで `pnpm --filter @sna-sdk/core test` や standalone サーバ実行
の準備完了。

## ランタイム CLI を確認

SNA はエージェントバイナリが `PATH` にあることを前提にする。素早い
確認:

```bash
claude --version
codex --version
opencode --version
```

非標準の場所にあるなら、呼び出し時に `providerOptions.cliPath` で
上書きするか、環境変数 `SNA_CLAUDE_PATH` / `SNA_CODEX_COMMAND` を
設定する。

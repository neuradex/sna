# Client SDK

`@sna-sdk/client` は実行中の SNA サーバーと通信します。コマンドと永続化には HTTP、push 購読には WebSocket、長時間ストリームには SSE を使います。

React 以外で使う場合や、独自 UI フレームワークの下位レイヤーとして使う場合に適しています。

## Install

~~~bash
pnpm add @sna-sdk/client@0.15.0
~~~

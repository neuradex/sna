# Core 설정

`getConfig`, `setConfig`, `resetConfig`는 애플리케이션이 runtime configuration을 조회하거나 덮어쓸 때 사용합니다. 호스팅된 process에서는 환경 변수가 가장 단순한 설정 방식입니다.
| 변수 | 의미 |
| --- | --- |
| `SNA_PORT` | 선호하는 서버 port입니다. |
| `SNA_MODEL` | 기본 model 이름입니다. |
| `SNA_PERMISSION_MODE` | 기본 permission mode입니다. |
| `SNA_MAX_SESSIONS` | 동시 session 최대 수입니다. |
| `SNA_DB_PATH` | 명시적인 database path입니다. |
| `SNA_DATA_DIR` | DB path가 없을 때 사용할 SNA data directory입니다. |
| `SNA_PERMISSION_TIMEOUT_MS` | permission prompt timeout입니다. |
| `SNA_OMLX_BASE_URL` | OMLX 호환 base URL입니다. |

## 함수 레퍼런스

### `getConfig()`

default, environment variable, runtime override가 적용된 effective SNA configuration을 반환합니다. Diagnostics와 server startup logging에 사용합니다.

### `setConfig(partial)`

현재 process에 runtime override를 적용합니다. Application preferences 화면에서 설정을 받아 embedded host가 반영해야 할 때 사용합니다.

### `resetConfig()`

runtime override를 지우고 configuration resolution을 default plus environment variable 상태로 되돌립니다. Test case 사이에 설정이 새지 않도록 테스트에서 사용하십시오.

### `SnaConfig`

SNA configuration의 typed shape입니다. Host-level settings UI를 만들거나 configuration object를 검증할 때 이 타입을 우선 사용하십시오.

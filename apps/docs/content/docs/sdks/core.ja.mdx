# Core SDK

`@sna-sdk/core` は最も低レベルのパッケージです。別プロセス内で SNA を実行する場合、独自サーバーから SNA を公開する場合、provider/runtime primitive を直接扱う場合に使います。

Core は React を前提にせず、ブラウザクライアントも必要としません。サーバー側のランタイム契約を担当します。

## Install

~~~bash
pnpm add @sna-sdk/core
~~~

# Core SDK

`@sna-sdk/core`는 가장 낮은 수준의 패키지입니다. 다른 프로세스 안에서 SNA를 실행하거나, 자체 서버를 통해 SNA를 노출하거나, provider/runtime primitive가 직접 필요할 때 사용합니다.

Core는 React를 가정하지 않으며 브라우저 클라이언트도 필요로 하지 않습니다. 서버 측 런타임 계약을 담당합니다.

## Install

~~~bash
pnpm add @sna-sdk/core
~~~

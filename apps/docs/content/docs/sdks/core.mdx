# Core SDK

`@sna-sdk/core` is the lowest-level package. Use it when you run SNA inside another process, expose SNA through your own server, or need provider/runtime primitives directly.

Core does not assume React and does not require the browser client. It owns the server-side runtime contract.

## Install

~~~bash
pnpm add @sna-sdk/core
~~~

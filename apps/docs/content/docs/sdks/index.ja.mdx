## バージョニング

4 パッケージは一緒にリリースされる。バージョンは SNA プロトコル
バージョンなので、コンシューマは 4 つとも同じメジャーに pin すべき。
リリースごとの表面変更は
[CHANGELOG](https://github.com/neuradex/sna/blob/main/CHANGELOG.md)
参照。

## ライブ OpenAPI 仕様

稼働中サーバは自身の OpenAPI 3.1 仕様を提供する。Swagger UI は
`http://localhost:3099/docs`、生 JSON は
`http://localhost:3099/openapi.json`、プレーンテキストは
`http://localhost:3099/spec`。仕様はルートが使うのと同じ Zod
スキーマから生成されるので、実際のハンドラとドリフトすることがない。

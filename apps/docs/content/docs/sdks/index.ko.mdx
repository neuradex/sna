## 버저닝

네 패키지는 함께 릴리즈됩니다. 버전은 SNA 프로토콜 버전이므로, 앱에서는
네 패키지를 모두 같은 메이저 버전으로 고정하는 것이 좋습니다. 릴리즈별 공개
API 변경은 [CHANGELOG](https://github.com/neuradex/sna/blob/main/CHANGELOG.md)에
정리됩니다.

## 라이브 OpenAPI 스펙

실행 중인 서버는 자신의 OpenAPI 3.1 스펙을 직접 제공합니다. Swagger UI는
`http://localhost:3099/docs`, 원시 JSON은
`http://localhost:3099/openapi.json`, 평문은
`http://localhost:3099/spec`. 스펙은 라우트가 쓰는 같은 Zod 스키마
에서 생성되므로 실제 핸들러와 드리프트할 수 없습니다.

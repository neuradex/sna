## 버저닝

4개 패키지는 같이 릴리즈된다. 버전은 SNA 프로토콜 버전이므로 컨슈머는
넷 모두를 같은 메이저로 고정해야 한다. 릴리즈별 표면 변경은
[CHANGELOG](https://github.com/neuradex/sna/blob/main/CHANGELOG.md) 참고.

## 라이브 OpenAPI 스펙

구동 중인 서버는 자신의 OpenAPI 3.1 스펙을 자체 제공한다. Swagger UI
는 `http://localhost:3099/docs`, 원시 JSON은
`http://localhost:3099/openapi.json`, 평문은
`http://localhost:3099/spec`. 스펙은 라우트가 쓰는 같은 Zod 스키마
에서 생성되므로 실제 핸들러와 드리프트할 수 없다.

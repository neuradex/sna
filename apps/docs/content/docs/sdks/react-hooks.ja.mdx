# React hooks

## `useAgent(options?)`

```ts
const agent = useAgent(options?: {
  sessionId?: string;
  baseUrl?: string;
  provider?: string;
  permissionMode?: string;
  reasoningLevel?: 0 | 1 | 2 | 3 | 4 | 5;
  providerOptions?: Record<string, unknown>;
  onEvent?: (event: AgentEvent) => void;
  onThinking?: (event: AgentEvent) => void;
  onAssistant?: (event: AgentEvent) => void;
  onToolResult?: (event: AgentEvent) => void;
  onComplete?: (event: AgentEvent) => void;
  onError?: (event: AgentEvent) => void;
  onInit?: (event: AgentEvent) => void;
});
```

`{ connected, alive, start, send, kill, completion }` を返します。この hook は mount 時に SSE event stream へ接続します。`start` は `/agent/start`、`send` は `/agent/send`、`completion` は `/agent/completion` を呼びます。

## `useSessionManager(pollInterval?)`

```ts
const manager = useSessionManager(pollInterval?: number);
```

`{ sessions, loading, createSession, killSession, deleteSession, refresh }` を返します。`pollInterval` の default は `3000` です。polling を無効にする場合は `0` を渡してください。

## `useResponsiveChat()`

```ts
const { mode } = useResponsiveChat(): { mode: "side-by-side" | "overlay" | "fullscreen" }
```

| Width | Mode | Meaning |
| --- | --- | --- |
| `>= 1024px` | `side-by-side` | chat panel を main content の横に置きます。 |
| `768px - 1023px` | `overlay` | chat panel を content の上に重ねます。 |
| `< 768px` | `fullscreen` | chat が viewport 全体を覆います。 |

# React SDK

`@sna-sdk/react` は client の上に React の状態境界を追加します。SNA を別の CLI ウィンドウではなく UI の一部として埋め込みたいアプリケーションに適しています。

provider 検出、セッションスコープ、チャットパネル状態、agent streaming を React コンポーネントの近くで扱います。

## Install

~~~bash
pnpm add @sna-sdk/react
~~~

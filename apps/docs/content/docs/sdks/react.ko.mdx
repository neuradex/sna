# React SDK

`@sna-sdk/react`는 client 위에 React 상태 경계를 더합니다. SNA를 별도의 CLI 창이 아니라 UI 일부로 임베드하려는 애플리케이션에 적합합니다.

Runtime 탐색, 세션 스코프, 채팅 패널 상태, agent streaming을 React 컴포넌트 근처에서 다룹니다.

## Install

~~~bash
pnpm add @sna-sdk/react@0.16.0
~~~

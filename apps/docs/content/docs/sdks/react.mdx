# React SDK

`@sna-sdk/react` builds on the client and adds React state boundaries. It is intended for applications that want SNA embedded as part of the UI rather than as a separate CLI window.

The package keeps runtime discovery, session scoping, chat panel state, and agent streaming close to React components.

## Install

~~~bash
pnpm add @sna-sdk/react
~~~

# Testing SDK

`@sna-sdk/testing` は、テストが実際の Anthropic または Claude アカウントに依存しないようにするためのパッケージです。ローカルの Anthropic 互換 API サーバーと、インスタンスごとに設定とログを分離する CLI wrapper を提供します。

スモークテスト、runtime adapter テスト、予測可能な agent 出力が必要な UI flow に使ってください。

## Install

~~~bash
pnpm add @sna-sdk/testing
~~~

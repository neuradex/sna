# Testing SDK

`@sna-sdk/testing` exists so tests do not need a real Anthropic or Claude account. It provides a local Anthropic-compatible API server and a CLI wrapper that isolates configuration and logs per instance.

Use it for smoke tests, provider-adapter tests, and UI flows that need predictable agent output.

## Install

~~~bash
pnpm add @sna-sdk/testing
~~~
